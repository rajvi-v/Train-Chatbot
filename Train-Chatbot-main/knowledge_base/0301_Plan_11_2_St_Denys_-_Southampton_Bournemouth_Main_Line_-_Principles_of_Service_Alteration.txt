Plan 11.2 St. Denys - Southampton Bournemouth Main Line. Category: line blockage. Location: St. Denys - Southampton Bournemouth Main Line. Blockage type: One line available through Southampton Tunnel Bi-directional signalling available. Audience: service_controller. Recommended action (service_alteration): Single line working over either line through Southampton Tunnel. Capacity agreed with Eastleigh SSM is 7 trains per hour. 1Wxx xx.05 Waterloo - Weymouth & return services run as booked. 1Bxx xx.35 Waterloo - Poole & return services run as booked 2Bxx xx.49 Winchester - Bournemouth & return services run between Southampton Central and Bournemouth 2Rxx xx 56 Salisbury - Romsey and return services run as booked 2Exx xx36 Portsmouth - Southampton & return services run as booked GTR: 1Jxx services to Southampton Central terminate / start at Fareham. GTR: 1Nxx services terminate/start at Barnham with stock and crew to step up by 2 circuits. From Southampton Central, any stock/crew to berth at Southampton Central Down Bay. (SWR Pilot Driver required for berth at SOU). GWR: Services to divert via Chandlers Ford / Botley if crew knowledge permits or terminate / start at Southampton Central. If no access to Southampton Central and the route via Chandlers Ford is unavailable then GWR to terminate at Salisbury. Control discuss with GWR crew requirements. CrossCountry : 1Oxx (Down) & 1Mxx (Up) services run as booked. Freight services to discuss with FOC as to diversion options via Romsey and Andover. If capacity needs to be freed up then consider terminating 2Exx services at St Denys with hold for connection into 2Sxx services or SSO for 1Bxx service.
