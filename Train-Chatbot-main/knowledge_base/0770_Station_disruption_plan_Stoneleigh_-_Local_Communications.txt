Station disruption plan for Stoneleigh. Category: station disruption. Location: Stoneleigh. Blockage type: station or platform disruption. Audience: station_staff. Recommended action (Local Communications): Local station communications with our customers should be managed proactively using regular station announcements in advance if possible. We know that station announcements are received well by our customers so it is important that we provide as much information as possible. If there is no information to provide at the time, this should be relayed to customers so they are kept up to date. If there are any issues with the equipment at this station, it should be faulted immediately. Remember, if there is a mobile mic at this station; please make sure it is used proactively so as to make sure our customers are kept up to date with whatever we know.
